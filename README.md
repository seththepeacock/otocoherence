# otocoherence
Analysis code for "[Spontaneous otocoherence of the active ear](https://www.biorxiv.org/content/10.1101/2025.11.14.687084v1)" [Peacock et al., 2025].

## Dependencies
The bulk of the calculations rely on our package [phaseco](https://seththepeacock.github.io/phaseco/).

## Data
Coming soon (though all data utilized have been previously published).

## Scripts
All analysis code is in `/scripts`. `soae_cgram_N_xi.py` will analyze all SOAE waveforms with the "peak-agnostic" method (and generate `.pkl` files of the analysis in `/pickles` for future use in plots), whereas `soae_peakc_N_xi.py` will analyze the same waveforms with the "peak-centric" method (using the identified peak centers in `picked_peaks.json` which can be generated by `soae_peakc_N_xi_peak_picking.py`). `nddho_N_xi.py` will simulate noise driven damped harmonic oscillator waveforms (using the function in `nddho_generator.py`) and analyze them with the peak-centric method. `soae_C_xi_P_peak_picking.py` performs the peak-picking analysis displayed in Figure 7. Finally, `paper_figs.ipynb` will generate all figures used in the manuscript.
